Upgrading from an earlier version
=================================

If you are upgrading an existing Litestar application to a newer major version, this is
the place to look. Each guide is ordered as work: what to do first, what breaks silently,
and how to find the affected code in your own project.

For the exhaustive list of changes in a release, see the
:doc:`changelog </release-notes/changelog>`.
